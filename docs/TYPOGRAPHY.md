# Typography

OnlyPlans uses Manrope for headings and the brand, Source Sans 3 for interface text and long report/chat passages, and Noto Sans KR for Korean fallback. Credits use tabular numerals where appropriate. Variable weights load through the existing Google Fonts CSS integration with display=swap.

The selection is a project-specific interpretation of the reading-focused guidance in [Awesome Claude Design](https://github.com/rohitg00/awesome-claude-design#picker-what-should-i-use), the restrained hierarchy in its [Linear reference](https://github.com/rohitg00/awesome-claude-design/blob/main/design-md/editorial/linear.md), and the heading/body separation in its [Granola reference](https://github.com/rohitg00/awesome-claude-design/blob/main/design-md/indie/granola.md). These references do not prescribe this exact font pairing. The existing Penn State colors and layouts are retained.
